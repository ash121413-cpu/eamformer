# 구현 계획

## 1. 파일 구성
| 파일 | 하는 일 |
|---|---|
| `streamlit_app.py` | 화면(로그인, 학생 화면, 관리자 화면). 단추는 `on_click` 콜백으로 처리 |
| `service.py` | DB 읽기/쓰기(지원, 투표, 마감, 명단 초기화, 확정). 모든 함수가 `(승인/대기/거절/막힘, 안내)`를 돌려줌 |
| `rules.py` | DB와 무관한 규칙 함수: `check_join`(지원·승인 직전 검사), `validate_assignment`(배정안 5가지 검사), `solve`(모든 경우를 따지는 배정), `infeasible_reasons` |
| `ai.py` | 오픈라우터 호출, 1·2·3차 폴백, 모델마다 전체 120초 제한 |
| `schema.sql` | `tf_` 테이블과 제약. 앱이 시작할 때 실행(IF NOT EXISTS) |
| `.github/workflows/keep-db-awake.yml` | 매일 DB 질의(일시정지 막기) |
| `tests/` | 연습 시나리오 3개를 화면 조작으로 돌리는 시험, AI 폴백 단위 시험 |

## 2. 단계
1. **DB 스키마**: 공고 5장 최소 참고안 + `tf_teams.team_no`, `tf_applications.decided_at`, `tf_ai_logs`. 대기 지원은 학생당 1건(부분 유일 인덱스)
2. **연결**: `psycopg_pool.ConnectionPool`을 `st.cache_resource`로 한 번만 만들어 재사용. Supabase 풀러를 위해 `prepare_threshold=None`
3. **로그인**: bcrypt 해시 비교. 세션에 학번만 저장, 매 화면에서 DB로 다시 확인
4. **명단 올리기**: `utf-8-sig`로 읽어 BOM 처리, 형식 검사 뒤 한 트랜잭션에서 모두 지우고 다시 만듦(관리자 계정은 남김)
5. **지원**: 팀 행을 `FOR UPDATE`로 잠그고 막힘 조건 검사 → 빈 팀이면 바로 팀원, 아니면 대기
6. **투표**: 팀 행 잠금 → 거부면 바로 거절 → 찬성이면 지금 팀원이 모두 찬성했는지 확인 → 승인 직전 `check_join` 재검사 → 빈 자리에 넣음(DB 유일성 제약이 최종 방어선). 처리 순서는 투표가 끝난 순서
7. **필수 포함 역할 자리**: 팀원 + 지원자에서 기획자/웹 프로그래머를 서로 다른 학생에게 맡기는 최대 매칭 수를 구하고, `남는 자리 < 2 - 매칭 수`면 막음
8. **마감**: 대기 → 거절, 1명뿐인 팀의 팀원 삭제, `closed=1`
9. **배정**: `solve`(백트래킹, 빈 팀 대칭 제거, 자리 가지치기)로 먼저 가능 여부 확인 → 불가면 이유 표시 → 가능하면 AI 1~3차 → 모두 실패하면 `solve`의 답. 배정안은 `tf_settings.proposal`에 저장
10. **AI 120초**: 요청을 스레드에서 돌리고 1초마다 경과를 확인해, 응답이 느리게 흘러와도 부른 때부터 120초가 지나면 기다리기를 끝냄. 기다리는 동안 `assign_status`에 "N차 모델 응답 대기 중, 경과 초" 표시
11. **확정**: 지금 상태로 배정안을 다시 검사한 뒤 한 트랜잭션에서 팀원으로 넣음
12. **자동 갱신**: 학생 화면 전체와 관리자 화면의 팀 현황을 `@st.fragment(run_every=3)`로 감쌈
13. **시험**: AppTest로 부록 시나리오 3개, 가짜 응답으로 AI 폴백(시간 초과→검사 실패→성공, 모두 실패), 헤드리스 크롬으로 key와 자동 갱신 확인
14. **배포**: 비공개 저장소 → Streamlit Cloud(Secrets 설정) → 공개 앱으로 전환 → 시크릿 창으로 확인

## 3. 위험과 대응
| 위험 | 대응 |
|---|---|
| 무료 모델이 느림/429/빈 응답 | 1·2·3차 폴백 + 앱 자체 배정, `reasoning.effort=low`, `max_tokens=6000` |
| 화면이 느림 | 연결 풀 재사용, 한 번 그릴 때 질의 6번으로 상태 전부 읽기 |
| 동시에 같은 자리 | 팀 행 잠금 + `(team_id, slot_no)` 기본 키 |
| DB 일시정지 | GitHub Actions 매일 질의 + 마감 날 직접 사용 |
