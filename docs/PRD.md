# PRD: 팀 프로젝트 팀 편성 웹 앱

## 1. 목표
학생이 팀 프로젝트의 팀을 스스로 편성하고, 모집 마감 뒤 남은 학생은 AI가 배정안을 내며, 앱이 그 배정안을 규칙으로 검사해 통과한 것만 관리자가 확정한다.

## 2. 사용자
| 사용자 | 하는 일 |
|---|---|
| 학생(가상 명단의 학생) | 학번과 비밀번호(1234)로 로그인, 팀 목록·팀원·역할 보기, 팀에 지원, 내 팀에 들어온 지원에 찬성/거부 |
| 관리자(`admin`) | 명단 CSV와 팀 수로 처음 상태 만들기, 모집 마감, AI 배정 받기, 배정안 확정 |

관리자 계정은 앱이 시작할 때 `ADMIN_PASSWORD`로 만들거나 비밀번호를 갱신한다. 명단을 다시 올려도 관리자 계정은 남는다.

## 3. 역할과 팀 규칙
- 역할 6개: 기획자, 웹 프로그래머, 프론트엔드 디자이너, 테스터, 보고서 작성자, 발표자
- 학생마다 주 역할 1개, 보조 역할 0~2개(명단에 정해짐, 바꾸지 않음)
- 확정한 팀은 모두 2~4명(빈 팀 없음)
- 한 팀에 주 역할이 같은 학생 2명 이상 금지
- 모든 팀에 기획자와 웹 프로그래머를 서로 다른 학생이 1명씩 맡음(주 역할 또는 보조 역할)

## 4. 기능 요구 사항
### 4.1 로그인
- 학번 + 비밀번호. 비밀번호는 bcrypt 해시로 저장. 틀리면 "막힘"
- 학생은 관리자 기능을 쓸 수 없음(서버 쪽에서 `is_admin` 확인)

### 4.2 지원과 투표
- 빈 팀 지원 → 바로 승인
- 팀원이 있는 팀 지원 → 대기, 투표하는 때의 팀원 모두가 투표
- 모두 찬성 → 승인 직전 재검사(정원, 주 역할 중복, 필수 포함 역할 자리) 뒤 승인 또는 거절
- 한 명이라도 거부 → 바로 거절. 투표는 바꿀 수 없음
- 막힘(지원을 접수하지 않음): 팀이 꽉 참, 같은 주 역할의 팀원, 이미 팀이 있음/결과를 기다리는 지원이 있음, 모집 마감, 필수 포함 역할을 맡을 학생의 자리가 모자람
- 필수 포함 역할 자리: 지원자가 들어간 뒤 남는 자리 수 < 아직 못 채운 필수 포함 역할 수 → 막음

### 4.3 마감과 배정
1. 마감: 대기 지원 거절, 1명뿐인 팀의 학생은 팀에서 빠짐
2. AI 배정: 먼저 규칙을 지키는 배정이 있는지 앱이 끝까지 따져 봄. 없으면 AI를 부르지 않고 "규칙을 지키는 배정이 없음"과 이유를 보여 줌
3. 있으면 오픈라우터 1차 → 2차 → 3차 모델 순으로 부름. 모델마다 전체 120초 제한. 빈 응답·오류·429·검사 실패도 실패로 보고 다음 모델로
4. 배정안 검사 5가지: 빠짐없이 배정, 한 학생은 한 팀, 모든 팀 2~4명, 주 역할 중복 없음, 필수 포함 역할 충족
5. 3차까지 실패하면 앱이 모든 경우를 따져 찾은 배정을 씀
6. 검사를 통과한 배정안만 보여 주고, 관리자가 확정하면 DB에 저장

### 4.4 화면
- 공고 2.7절의 Streamlit `key`를 그대로 씀(`login_student_no`, `result`, `team_1`, `apply_1`, `vote_yes_{학번}`, `admin_assign`, `assign_status` 등)
- `result`의 안내는 "승인/대기/거절/막힘"으로 시작
- 다른 사람의 변경은 `st.fragment(run_every=3)`으로 바뀐 부분만 3초마다 다시 그림
- AI 대기 중에는 "N차 모델(이름)의 응답을 기다리는 중… 경과 초"를 보여 줌

## 5. 비기능 요구 사항
- 키 관리: `OPENROUTER_API_KEY`, `DATABASE_URL`, `ADMIN_PASSWORD`는 `.env`/Streamlit Secrets에만 둠. 화면에는 "있음/없음"만 표시
- DB: Supabase(6장 프로젝트 재사용), 테이블은 모두 `tf_`로 시작, 연결 풀로 연결을 재사용
- 유일성 제약: `tf_members`의 `(team_id, slot_no)` 기본 키와 `student_id` 유일 → 마지막 자리에는 먼저 도착한 학생만 기록
- DB 일시정지 막기: GitHub Actions 예약 실행으로 매일 DB에 질의
- 배포: Streamlit Community Cloud. 서버 시각(UTC)은 한국 시각으로 바꿔 표시
